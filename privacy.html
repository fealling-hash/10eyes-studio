개인정보처리방침

시행일: 2026년 11월 18일

10초 눈썰미 스튜디오(이하 "이 도구")는 유튜브 채널 10초 눈썰미(@10eyes_1)의 운영자가 본인 채널 관리를 위해 사용하는 개인용 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

1. 수집·이용하는 정보

  • Google 계정 인증 정보(OAuth 토큰): 운영자가 직접 승인하면 발급되며, 운영자 채널에 영상을 업로드하는 데에만 사용합니다.
  • 유튜브 채널 정보: 채널 ID, 채널 이름, 핸들, 업로드 재생목록 ID — 올바른 채널에 업로드하는지 확인하는 데 사용합니다.
  • 채널의 동영상 정보: 동영상 ID, 제목, 공개 상태, 공개 예정 시간 — 관리 화면의 목록과 맞추는 데 사용합니다.

이 도구는 시청자 정보, 댓글 작성자 정보, 다른 사용자의 정보를 수집하지 않습니다.

2. 보관 위치와 기간

  • 모든 정보는 운영자 본인의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.
  • YouTube API에서 받은 정보는 화면 표시와 업로드 관리 목적으로만 보관하며, 갱신이 필요한 정보는 최대 30일마다 다시 받아오거나 삭제합니다.
  • 운영자가 연결을 해제하면 저장된 인증 정보는 삭제됩니다.

3. 제3자 제공

이 도구는 수집한 정보를 판매하거나 제3자에게 제공하지 않으며, 광고 목적으로 사용하지 않습니다.

4. 접근 권한 철회

언제든지 Google 계정 보안 설정의 서드파티 연결 페이지에서 이 도구의 접근 권한을 취소할 수 있습니다. 권한을 취소하면 이 도구는 더 이상 채널에 접근할 수 없습니다.

Privacy Policy

Effective date: November 18, 2026

10-Second Sharp Eyes Studio ("the App") is a private tool used only by the owner of the YouTube channel 10초 눈썰미 (@10eyes_1) to manage that channel. The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information accessed

  • OAuth tokens granted by the channel owner, used only to upload videos to the owner's own channel.
  • Channel information (channel ID, title, handle, uploads playlist ID), used to confirm uploads go to the correct channel.
  • Video information of the owner's channel (video ID, title, privacy status, scheduled publish time), used to keep the local dashboard in sync.

The App does not collect information about viewers, commenters or any other users.

Storage and retention

  • All data is stored only on the owner's own computer. It is never sent to any other server or shared with third parties.
  • Data obtained from the YouTube API is kept only for display and upload management, and is refreshed or deleted at least every 30 days where required.
  • Stored credentials are deleted when the owner disconnects the channel.

Sharing

The App does not sell, share or use any data for advertising.

Revoking access

Access can be revoked at any time via the Google security settings page.
